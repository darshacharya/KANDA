// architecture

Three-layer safety pipeline

🧠

Deliberative Layer

Groq Llama 3.3 70B classifies intent (COMMAND/QUESTION/TASK/UNKNOWN) and generates validated JSON action plans with body-context grounding.

⚖️

Critic Layer

Pi-side validator enforces action ∈ {forward, backward, left, right, slight_left, slight_right, stop}, clamps speed [0–255], rejects unsafe plans.

⚡

Reflex Layer

ESP32 firmware halts in 47ms when front sensor < 15cm — 40× faster than cloud round-trip. Works even if Pi crashes.

🔍

ReAct Search

Spiral pattern: 4 rotations for 360° scan → forward → rescan → turn opposite → forward. Semantic memory (SequenceMatcher > 0.7) prevents revisiting.

👁️

Vision + Body Context

NVIDIA NIM VLM describes scenes. Body context injects sensors, recent actions, conversation, camera scene, and capabilities into every LLM call.

🎙️

Wake → Act Pipeline

"Hey Kanda" → VAD recording → Groq Whisper STT → intent classification → plan execution → gTTS response. Full cycle in 7 states.
