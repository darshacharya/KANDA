What KANDA can do

🎙️

Voice Control

Wake with "Hey Kanda", speak naturally. Groq Llama 3.3 classifies intent and generates validated motor plans in real-time.

👁️

Vision Understanding

NVIDIA NIM Llama 3.2 Vision describes scenes, identifies objects, and guides the episodic visual search algorithm.

🔍

Object Search

"Find my bottle" — triggers a ReAct-style search loop with semantic deduplication memory to avoid revisiting explored areas.

🛡️

Three-Layer Safety

Deliberative grounding + deterministic validator + firmware reflex. 42% of raw LLM outputs are unsafe — after validation, zero.

📱

Telegram Remote

Send text commands, voice notes, or photos via Telegram. All paths converge at intent classification with full body context.

⚡

Real-time Reflex

ESP32 firmware halts in 47ms on obstacle detection — 40× faster than cloud inference. Works even if Pi is disconnected.
