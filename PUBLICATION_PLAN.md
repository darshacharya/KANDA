# KANDA Paper Publication Plan

**Paper:** "KANDA: A Multimodal Embodied Robot Agent Driven by Large Language Models for Hardware-Conscious Command Generation"  
**Authors:** Sudarshan T S, Sushmitha N (RV College of Engineering, Bengaluru)  
**Date:** June 1, 2026

---

## Paper Summary

KANDA is a $77 multimodal embodied robot agent (ESP32 + Raspberry Pi 4 + camera) with voice, vision, text, and Telegram input. Uses Groq Llama 3.3 for text reasoning and NVIDIA NIM Llama 3.2 Vision for visual understanding. Features a deliberative-critic-reflex safety architecture based on Brooks' subsumption model. Key results: intent F1 = 0.94, visual search 80% success, all 8 injected faults terminate safely.
