# KANDA Images

Place the following photos/screenshots in this directory:

| Filename | Description | Used in |
|----------|-------------|---------|
| `kanda_robot.jpg` | Full robot assembled, top/front view | Chapter 1, Paper |
| `architecture.png` | Three-tier cloud / edge / device diagram | Paper |
| `dataflow.png` | Full interaction cycle data-flow | Paper (figure*) |
| `statemachine.png` | Seven-state machine diagram | Paper |
| `kanda_side.jpg` | Robot side view showing sensors and wheels | Chapter 3 |
| `wiring_closeup.jpg` | ESP32 + TB6612FNG + sensor wiring closeup | Chapter 6 (optional) |

Recommended image specs:
- Photos: minimum 1200px wide, good lighting, plain background
- Screenshots: high-DPI capture, crop to relevant area
- Format: JPG for photos, PNG for screenshots
