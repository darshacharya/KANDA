\section{Reflections}
\label{sec:reflections}

Three lessons stood out during integration. First, \textbf{contract discipline} on the serial line (one JSON object per line, fixed telemetry pattern) saved debugging time compared to ad-hoc byte streams. Second, \textbf{separating rates}---fast local sensing versus slow cloud reasoning---avoided false expectations about real-time LLM latency~\cite{vemprala2024chatgpt}. Third, \textbf{validation as a product feature}, not an afterthought, made it safe to iterate on prompts without risking arbitrary motor verbs~\cite{huang2023grounded}.

\section{Closing Remarks}
\label{sec:ch9closing}

KANDA shows that a small, low-cost mobile platform can host a credible sense--reason--validate--act loop when LLM outputs are constrained and firmware retains autonomous competence. The work is a stepping stone toward richer perception and planning (Phase~4), not an endpoint. Readers pursuing similar projects should budget time for serial reliability, level shifting, and documented safe-stop behaviour before expanding model capability.

This report therefore ends with the objectives mapped to evidence, the main technical findings in Chapter~\ref{ch:results}, and the bibliography that grounds the work in embodied AI and robotics practice.
